# 意思決定ログ

設計・技術選定における判断とその理由を記録する。
「何をどう書くか」というルールは [CODING_GUIDELINES.md](./CODING_GUIDELINES.md) を参照してください。

## 記入テンプレート

新しい決定を追記するときは、このフォーマットをコピーして一番下に追加する。

```md
## YYYY-MM-DD: タイトル

- **背景**: なぜこの判断が必要だったか
- **決定**: 何を決めたか
- **理由**: なぜこの選択にしたか(検討した代替案があれば併記)
- **影響**: この決定によって今後どう変わるか / 次に何をする必要があるか
```
